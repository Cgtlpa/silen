Why Silen?

A small system that stays out of your way.

Independent

Own ISO builder, live init, offline installer, and package manager. No upstream respin — Silen is its own distro.

Minimal by design

BusyBox live RAM root, whiptail installer, clean base install. You add only what you need — nothing pre-forced.

Hardware ready

Storage, wired, USB tethering, broad Wi-Fi coverage, and GPU firmware merged in so live boot modesets instead of black-screening.

Offline installer

Full base install with no network needed. GPT + ESP + root, ext4 / btrfs / vfat, hostname, users, timezone — done in minutes.

spk packages

One Rust tool: spk get / find / rm. System packages go to /, leaf apps stay isolated with shims.

Diagnostics built in

silen-wifi-check and silen-nvidia-check dump everything needed to debug wireless and GPU issues.

Install in minutes

Base only, offline. Desktops and drivers come after reboot via spk.

  1. Flash the ISO — dd to USB, or boot it via Ventoy.
  2. Boot UEFI — pick Silen Linux (or fallback nomodeset).
  3. Run the installer — pick disk, filesystem, hostname, users.
  4. Reboot, then extend — spk get linux-firmware, GPU drivers, your desktop of choice.
# after first reboot, with network:
spk get linux-firmware
spk get plasma-desktop   # or gnome, xfce, i3, sway …
spk get mesa xorg-server xinit dwm   # lightweight X11 path
