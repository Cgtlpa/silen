Reliable by default. Powerful when you want it.

Silen Linux is an independent, lightweight distribution - a minimal live environment that installs a clean base you build on. No forced desktop, no bloat; the builder, live init, installer and package manager are its own - not a remix.

Hardware

Broad in-tree drivers and firmware ship on the ISO - storage, Wi-Fi and GPUs (amdgpu, i915, xe, nouveau, radeon). NVIDIA cards run on nouveau; the NVIDIA ISO or spk get nvidia-drivers adds the proprietary driver.

Install

A fully offline text-menu installer that finds the install medium itself.

  1. Write the ISO to USB (dd or Ventoy) and boot in UEFI mode.
  2. The disk is wiped and laid out as GPT: ESP + root.
  3. Answer a few prompts - user, locale, keymap, timezone, swapfile.
  4. Reboot, connect to the internet and run the setup wizard:
iwctl        # connect to Wi-Fi
silen-setup  # wizard: desktop, login manager, firmware, extras

Packages

spk installs system packages into / and keeps leaf apps isolated under /spk_pkgs. 228 packages are in the repository:

spk get linux-6.18        # precompiled kernel + modules
spk get nvidia-drivers    # proprietary NVIDIA driver, guided install
spk get fastfetch vim git htop tmux   # everyday tools
