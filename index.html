Reliable by default. Powerful when you want it.

Silen Linux is an independent, lightweight distribution. It boots as a minimal live environment and installs a clean base system you build on top of — no bloat, no forced desktop, full control. The project ships its own ISO builder, live init, offline installer, and package manager rather than remixing another distribution.

hardware

The live ISO carries a broad driver set so it boots on real hardware, not just VMs:

  • Storage: AHCI, NVMe, virtio-blk/scsi, MMC/SDHCI, USB storage and UAS.
  • Wired + tethering: e1000/e1000e, r8169, igb, r8152, alx, cdc_ether, rndis_host, and more.
  • Wi-Fi: Intel iwlwifi, Atheros ath9k/10k/11k/12k, MediaTek mt76/mt79xx, Realtek rtw88/rtw89/rtlwifi, Broadcom brcmfmac/b43, plus Marvell, Ralink, and TI chipsets.
  • Graphics: in-tree kernel drivers (amdgpu, i915, xe, nouveau, radeon) with firmware merged into both the live boot and offline installs, so the display modesets instead of black-screening. NVIDIA cards fall back to nouveau; the proprietary driver installs later via spk get nvidia-drivers.

install

The installer is a text-menu (whiptail) flow that works fully offline and installs the base system only. It finds the install medium automatically, including ISO-file boot via Ventoy.

  1. Write the ISO to USB (dd; Ventoy also works) and boot in UEFI mode.
  2. Choose Install. The disk is wiped and laid out as GPT: a 1 MiB–513 MiB EFI partition plus root (ext4 or btrfs).
  3. Set hostname (default silen), root password, an optional user, locale, keymap, timezone, and swapfile.
  4. Reboot into the installed system, then extend it:
spk get linux-firmware    # wifi + device firmware
spk get mesa              # OpenGL / Vulkan graphics stack
spk get instantwm         # window manager (X11/Wayland)
spk get sddm              # login screen (or: ly)

packages

spk is a small single-binary manager. System packages — kernels, firmware, drivers, login managers — install straight into /, while leaf applications stay isolated with shims in /usr/local/bin. A few real examples from the package repository:

spk get linux-6.18        # precompiled Silen kernel + module tree
spk get nvidia-drivers    # proprietary NVIDIA driver, guided install
spk get fastfetch vim git htop tmux   # everyday tools

diagnostics

Two tools ship for debugging: silen-wifi-check dumps wireless state (modules, interfaces, rfkill, dmesg, iwd) to a log, and silen-nvidia-check covers GPU/driver state. silenfetch prints the Silen logo and system info (needs spk get fastfetch first).
