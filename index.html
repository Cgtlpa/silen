About

Join the Discord!

Silen ships a stage3 tarball on the install medium, in the same spirit as Gentoo. The live environment is thin: busybox, glibc, networking, git and curl. The whole system is the initramfs, so there is nothing to install until you say so

The package manager, spk, is written in Rust. Packages are pulled straight from a git-hosted repo

Why

Silen Linux is made to stay out of your way, its suppost to be stable while still maintaining newer software

  • fast boot
  • Simplicity Matters
  • updates only when something actually matters
  • nothing installed that wasn’t picked on purpose
