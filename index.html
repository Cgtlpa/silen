Silen Linux

Reliable by default. Powerful when you want it.

Silen Linux is an independent, lightweight distribution. It boots as a minimal live environment and installs a clean base system you build on top of — no bloat, no forced desktop, full control. Version 1, kernel 6.18, OpenRC, x86_64 UEFI-only.

Installation

The installer works fully offline and installs the base system only. Extras (firmware, drivers, window manager) come after reboot via spk.

  1. Write the ISO to USB (dd; Ventoy also works) and boot in UEFI mode.
  2. Run the installer: pick disk (it will be wiped → GPT + ESP + root), filesystem (ext4/btrfs), hostname, users.
  3. Reboot, then extend the system:
spk get linux-firmware    # wifi + device firmware
spk get mesa              # OpenGL / Vulkan graphics stack
spk get instantwm         # window manager (X11/Wayland)
spk get sddm              # login screen (or: ly)

Package management

spk installs system packages (kernels, drivers, firmware, login managers) straight into /, and keeps leaf applications isolated with shims in /usr/local/bin. Browse the package repository.

Diagnostics

Built-in tools: silen-wifi-check for wireless issues, silen-nvidia-check for GPU/driver issues. silenfetch prints the Silen logo and system info (needs spk get fastfetch).
