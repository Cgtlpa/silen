Requirements

  • x86_64 PC - main images need UEFI boot; Silen Arch also boots BIOS.
  • A USB stick and a disk the installer may wipe (GPT).
  • Root on ext4, btrfs or fat32; the base install is offline.

Write to USB

# replace sdX with your stick
sudo dd if=silen-linux.iso of=/dev/sdX bs=4M status=progress oflag=sync

Ventoy works too - the medium is found automatically.

First boot

iwctl        # connect to Wi-Fi
silen-setup  # wizard: desktop, login manager, firmware, extras
silenfetch   # logo + system info
