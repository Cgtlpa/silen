download

Current release: v1, kernel 6.18.54. ISOs are hosted on Hugging Face (GitHub caps files at 2 GB).

images

VariantFileNotes
Standard silen-linux.iso (1.8 GB) Recommended for most PCs. Open drivers with in-tree GPU firmware (amdgpu, i915, xe, nouveau, radeon). NVIDIA cards work via nouveau; proprietary drivers install later with spk get nvidia-drivers.
NVIDIA silen-linux-nvidia.iso (2.2 GB) Same base system. Installs the proprietary NVIDIA driver automatically when an NVIDIA GPU is detected (skipped otherwise, nouveau stays active).

requirements

  • 64-bit (x86_64) PC with UEFI boot — legacy BIOS is refused by the installer.
  • A USB stick and a disk the installer may wipe (GPT: ESP + root).
  • Root filesystems: ext4, btrfs. No network needed for the base install.

write to usb

# verify the checksum first (see Checksums above)
sha256sum silen-linux.iso

# write to USB (replace sdX with your stick!)
sudo dd if=silen-linux.iso of=/dev/sdX bs=4M status=progress oflag=sync

Ventoy ISO-file boot is detected automatically.

first boot

iwctl                  # configure Wi-Fi if needed
spk get linux-firmware # wifi + device firmware
spk get fastfetch      # needed by silenfetch below
silenfetch             # logo + system info
