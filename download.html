Download

Current release: v1, kernel 6.18.54. All ISOs and checksums are published on the Releases page.

ISO images

VariantFileNotes
Standard silen-linux.iso Recommended for most PCs. Open drivers with in-tree GPU firmware (amdgpu, i915, xe, nouveau, radeon). NVIDIA cards work via nouveau; proprietary drivers install later with spk get nvidia-drivers.
NVIDIA silen-linux-nvidia.iso Same base system. Installs the proprietary NVIDIA driver automatically when an NVIDIA GPU is detected (skipped otherwise, nouveau stays active).

Requirements

  • 64-bit (x86_64) PC with UEFI boot — legacy BIOS is refused by the installer.
  • A USB stick and a disk the installer may wipe (GPT: ESP + root).
  • Root filesystems: ext4, btrfs. No network needed for the base install.

Write to USB

# verify the checksum first (see Releases page)
sha256sum silen-linux.iso

# write to USB (replace sdX with your stick!)
sudo dd if=silen-linux.iso of=/dev/sdX bs=4M status=progress oflag=sync

Ventoy ISO-file boot is detected automatically.

After installing

iwctl                  # configure Wi-Fi if needed
spk get linux-firmware # wifi + device firmware
spk get fastfetch      # needed by silenfetch below
silenfetch             # logo + system info
