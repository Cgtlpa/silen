Looking for a version? All ISOs, checksums, and changelogs live on the SilenLinux Releases page. Current: v1 · kernel 6.18.54.

Requirements

  • 64-bit (x86_64) PC with UEFI boot — legacy BIOS is refused by the installer
  • USB stick (or Ventoy) + a disk the installer may wipe
  • GPT layout created automatically: 1 MiB–513 MiB ESP + root
  • Root filesystems: ext4, btrfs, vfat

Flash it

# check checksum first (see Releases page)
sha256sum silen-linux.iso

# write to USB (replace sdX with your stick!)
sudo dd if=silen-linux.iso of=/dev/sdX bs=4M status=progress oflag=sync

Ventoy ISO-file boot is also detected automatically.

After install

iwctl                  # configure Wi-Fi if needed
silenfetch             # show the Silen logo + system info
spk get linux-firmware # firmware, drivers, desktops…
