spk

spk is the Silen package manager - a single Rust binary, no daemon. System packages install into /; leaf apps stay isolated under /spk_pkgs with shims in /usr/local/bin. After the first reboot, silen-setup installs your desktop, login manager and extras through it.

spk get <pkg...>      # install (pulls dependencies too)
spk list              # what is installed
spk find <pattern>    # search installed packages
spk update [pkg...]   # update installed packages
spk rm <pkg...>       # remove
spk self-update       # update spk itself
